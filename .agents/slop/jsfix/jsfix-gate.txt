ABI-6 -- CLASSIFIED, NOT COUNTED BLIND
==============================================================================
  `abi.json` states ABI-6 as 'both lanes answer 0 where tinygrad's helpers
  raise ZeroDivisionError'.  That is TRUE OF `ceildiv` AND FALSE OF THE
  OTHER FOUR: tinygrad/helpers.py:74 and :77 guard `cdiv` and `floordiv`
  with an explicit `if y != 0 else 0`, so only `ceildiv` ever raises.
  A block that reported 5 divergences here would have counted 4 agreements
  as divergences, which is JSL2-7 with the sign flipped.
  floor_div  tinygrad -> 0:0                                    node 0:0        cc 0:0        agree
  floor_mod  tinygrad -> 0:7                                    node 0:7        cc 0:7        agree
  cdiv       tinygrad -> 0:0                                    node 0:0        cc 0:0        agree
  cmod       tinygrad -> 0:7                                    node 0:7        cc 0:7        agree
  ceildiv    tinygrad -> ZeroDivisionError: division by zero    node 0:0        cc 0:0        DIVERGE

  1 diverge (ceildiv), 4 agree.  Counted `diverge`, never `pass`: the lanes
  AGREE on the zero divisor, so no lane-against-lane check can see this,
  and an oracle that called floordiv(7, 0) would raise inside this gate.
