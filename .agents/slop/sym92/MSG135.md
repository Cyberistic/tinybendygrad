`mixin/elementwise.py:40`:

    def usum(self, *uops): return functools.reduce(operator.or_ if self.dtype is dtypes.bool
                                                   else operator.add, uops, self)

The port's `sy_usum` ALWAYS added, and its own comment admitted it: *"The `or_`/`and_` special case
for a bool `self` is NOT PORTED; every caller in `symbolic.py` that reaches a bool is a rule this file
defers."* **A COMMENT THAT ADMITS A DIVERGENCE IS STILL A DIVERGENCE** -- on a bool receiver `ADD` and

FIXED: the op is read off the receiver's dtype (`F.dt_is(F.folded(ar), base, S.boolean())`) and

The probe reads the BOOL TEST and not the answer, because `sy_usum` returns an INDEX without the
