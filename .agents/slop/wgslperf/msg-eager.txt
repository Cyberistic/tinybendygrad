1. `Arena.node` IS `Maybe.default(&1, Node, Arena.at(ar, i), Arena.bottom())`, AND
   `Maybe.default` EVALUATES ITS DEFAULT EAGERLY -- SO EVERY LOOKUP BUILT A NODE IT DID NOT
   USE, AND THE ARENA's LOOKUP IS THE HOTTEST PATH IN THE PORT (3,577,720 LOOKUPS A TURN). THE
   DEFAULT IS NOW BUILT IN THE MISS ARM.

2. `Topo.cache_add` APPENDED TO THE TOPOSORT's CACHE, AND `List.append` COPIES THE WHOLE LIST,
   SO THE CACHE WAS O(n) PER NODE. THE CACHE IS NOW CONSED, AND THE ORDER IS RESTORED ONCE, AT
   THE END, WHERE THE TOPOSORT's OUTPUT IS THE VISIT ORDER (⇒⇒† AND **AND **THE ORDER **IS **THE
   **ONLY **THING **THE **CACHE's **ORDER **IS **FOR**). MEASURED: `Topo.cache_add` WAS 2.6% OF
   THE TURN's EXCLUSIVE TIME.
