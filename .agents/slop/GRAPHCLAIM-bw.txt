**The float-CONST finding, stated before the edit because it changes what the edit IS.**

`--graph bw` is the corpus's FIRST float CONST (`graphcmp-LIMITS.md` §2 says "still 0 of the
189 nodes across 16 graphs has a float CONST, so the choice remains untested rather than
measured"). The measurement is now made and it is a DEFECT, on both sides:

  py   `konst` -> `f` + `repr(ConstFloat(1.0))`  = `fConstFloat(1.0)`
  bend `konst` -> `f` + `F32.show(1.0)`         = `f1`

Both are wrong in the same way and for the same reason: each side's own spelling of a float,
and the two spellings were never compared because no fixture had one. `F32.bits` is a law
(base.bend:1701) and MEASURED `F32.bits(1.0) = 1065353216`, which is exactly CPython's
`struct.pack('<f', 1.0)`, so BOTH sides can spell a float CONST as its f32 BITS and the
column becomes exact instead of textual. That is the fix; the alternative -- leaving `repr` in
a structural field -- is the thing this whole file exists to forbid.
