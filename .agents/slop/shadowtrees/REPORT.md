# Shadow-tree classification — `.agents/slop` full copies of the source tree

**STATUS: IN PROGRESS. DELETE NOTHING. NOTHING DELETED. NOTHING COMMITTED.**

Unit: `shadowtrees` — owns `.agents/slop/shadowtrees/` and `.agents/slop/_cleanup/`.
No `bend` process is invoked by this unit. No build, no compile, no `cp -R` of a source tree.

Method per tree, three separate questions, never one standing in for another:
1. **RECREATABLE?** — name the exact command. Proven by finding the maker, not by guessing.
2. **CITED?** — does a COMMITTED report name a path INSIDE it? Measured as a WHOLE PATH TOKEN.
3. **ONLY COPY?** — does anything in it differ from its real counterpart, such that the copy
   (not the diff) is the artifact?

Sections fill in as measurements land.
