### b3

Slots is not a micro-optimisation. It removes the instance dictionary. A Tensor is three pointers. This compiler makes one Python object for every node in the graph, so a hundred thousand nodes means a hundred thousand of these — and with a dict on each one, that is a different program.

*cue:* 01.1.3
*lines:* 55

*direction:* pause before 'a different program'
