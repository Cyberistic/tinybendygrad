### b1

Everything in this compiler compares nodes. If comparison means walking two trees, every rewrite is quadratic. So tinygrad makes equal nodes identical, and equality becomes a pointer compare.

### b3

Why the type of arg? Because True equals one as a dict key. Without it, a constant storing True and a constant storing one are the same node. The comment says this. It is the kind of bug that would take a day to find.

### b4

A hit has to return something alive. The cache holds a weak reference, so the entry can outlive the node. Two checks, not one: the slot exists, and the referent still exists. A dead pointer here is a crash, not a miss.

*direction:* underline the nested is-not-None

### b5

A miss constructs the node, then stores a weak reference to it. Which means: drop every Tensor and the graph collects itself. There is no registry to clean up and no shutdown path to get wrong.
