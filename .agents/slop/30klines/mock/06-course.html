thirty thousand lines.
every one of them.

tinygrad compiles a tensor program to a GPU kernel in about thirty thousand lines of Python. This course reads every line that matters, in the order that makes it make sense.

We do not start at line one. We start at Tensor, jump straight to the kernel that actually runs, and then walk back through each stage that transformed it — because the end tells you what the middle is for.
