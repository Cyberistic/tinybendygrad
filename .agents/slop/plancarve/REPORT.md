## 3. The carve-out, designed (and why the writer path was chosen instead)

`AGENTS.md` doctrine 1: *"a population is (a) a generator's own declaration, loaded by path …"*, and
*"a second copy of the list is a contract with no generator."* The two named options were exactly
"each fixture declares its own plant set" or "the writer's output extension becomes `.out`". **The
second is correct here**, because the e2e files are OUTPUT, not constants: they carry no declaration
to load. A carve-out for them would excuse a real extension defect. So the writer's extension was
changed; no list was added.
